# Changelogs

Registo de todas as mudanças ao projeto, um ficheiro por dia (`AAAA-MM-DD.md`).

## Modelo de um ficheiro de dia

```markdown
# AAAA-MM-DD

## HH:MM — Título curto da mudança

- **O quê:** o que foi adicionado, alterado ou removido
- **Porquê:** motivo ou decisão por trás
- **Ficheiros:** caminhos afetados (se aplicável)
```
